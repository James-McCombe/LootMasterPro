# LootMasterPro

LootMasterPro is an addon for **World of Warcraft** that enhances loot chat messages. It replaces the standard text with expanded details about your inventory using data from **TradeSkillMaster**.

## Features

- Injects bag, bank, and alt counts into loot messages.
- Displays market and vendor values for looted items.
- Slash command `/getiteminfo` shows item data on demand.
- `/lmpdebuglevel` adjusts addon debug output.
- Includes commands to toggle All The Things debug mode.
